田中正平 純正調オルガン Web版（iPad横向き試作）
================================================

【公開手順】
1. ZIPファイルを解凍します。
2. 中にある「tanaka-organ」フォルダを、reiji-lab.org の
   GitHub Pages公開元リポジトリの公開ルートにアップします。
3. GitHub Pagesの反映後、iPadのSafariで以下を開きます。

   https://reiji-lab.org/tanaka-organ/

※ 公開元が別のサブディレクトリにある場合は、実際の公開ルートに
   「tanaka-organ」フォルダを置いてください。
※ サイトの既存ファイルは上書きしないでください。
※ index.html・style.css・app.js は同じフォルダに置きます。
※ 追加ライブラリ・npm・Mac・サーバー処理は不要です。

【操作】
・iPad横向き（12.9インチ・第4世代を基準にデザイン）。
・最初に「♪ 音を有効にする」をタップしてください。
・鍵盤をタッチ／マウスで押すと音が鳴り、離すと止まります。
・複数指で和音、指を横に動かして鍵盤間の移動が可能です。
・SUSTAIN はタップでON/OFF。ON中は指を離しても保持します。
・P / O は従来の比率切替。
・18個の調名をクリックするとその調に移調します。
・小文字の調名は短調、大文字は長調です。
・−1 の付いた調名は固定比率の音名で、独立した操作ではありません。
・鍵盤には音名と正確な比率を両方表示。Z、XなどのPCキー文字は表示しません。
・P/Oや長短調が変わると、該当鍵盤の音名と比率が更新されます。
・画面の比率は移調のみでは変わりません。長短調・P/O切替では変わります。
・上のオクターブは基準Cからの比率を表示（例：中間のC=2/1、右端のC=4/1）。
・音名は独語式（B＝変ロ、H＝ロ）。A−1調で125/72となる鍵の表示をB−2に修正しました。
・未確定の音名は引き続き「≈」付きの暫定表示です。歴史的な音名の確定ではありません。
・正しい音高の判定は必ず表示される有理数比率を基準としてください。
・−1 oct / +1 oct / 基準に戻す：オクターブ移動（−2～＋2）。
・全消音：音をすべて止めます。
・PCでマウス操作可能。PCキーボードの音符キー割当はありません。

【構成】
  tanaka-organ/
    index.html    …… 画面
    style.css     …… レイアウト
    app.js        …… 音声合成・比率計算・タッチ/マウス操作
    README.txt    …… この説明
    sw.js         …… オフライン用キャッシュ

【技術・精度に関する注意】
・基音はC=261.625565Hz。18調比率はユーザー指定の18行を使用。
・F♯−1＝45/32、短調白鍵・短調P切替もユーザー指定の比率。
・43音＝15白鍵＋28上鍵（中央の共通主音は1回だけ）。
・選択調名を押すと鍵盤の音名は更新され、鍵盤の比率は変化しません。
・音はWeb Audio APIによる7倍音・非線形波形の再合成＋起音エコー。
  Python 1.4/1.5のPCMをそのまま移したわけではありません。
  音色・遅延はiPad Safariの実機で検証・調整してください。
・音量が急増する和音に備えリミッター相当のコンプレッサーを使用。
・外部ネットワーク上のライブラリや音源ファイルは参照しません。
・Safariでは他のタブへの移動後、再び音声有効化が必要な場合があります。
・本番はiPhoneのテザリングから接続可能。音源はWeb Audioで端末内生成するので、ロード後の音の演奏に通信は使いません。
・初回オンライン閲覧時に静的資材をキャッシュします。通信途絶時はキャッシュを利用する設計ですが、Safariの状態に左右されるため、リハーサルで必ず機内モードにしてテストしてください。
・オフラインでも再読み込みできることは保証できないため、発表前にページを開いて音が出る状態にしておくのが安全です。
・演奏本番に備え、iPadの「集中モード」や画面自動ロック、電池残量も確認してください。
・アプリは音名と比率を表示しますが、特に未確定の移調後の音名には≈を付けています。博士による検証前の仮表示です。
・既存のreiji-lab.orgのHTML/CSS/JSには干渉しません。
・オンライン優先のキャッシュに変更。更新を反映するときはSafariでページを再読み込みしてください。

【2026年12月22日の演奏発表に向けた確認項目】
1. Safari（iPad Pro 12.9インチ 第4世代）を横向きで開き、表示が収まること。
2. 最初に「音を有効にする」を押し、単音・和音・同時タッチ・指の移動を確認すること。
3. 18調の各比率を参照表と比較すること。特にF♯−1=45/32を確認。
4. P/O、長短調、SUSTAIN、全消音を演奏手順に沿って試すこと。
5. 本番前にオンラインで一度読み込み、その後機内モードでも再起動できるか必ず確認すること。
6. Safariがスリープしたときの音声再開、音量、iPadの通知・自動ロックを確認すること。
7. 本番は必要に応じて従来の動作確認済みPython版を予備に用意すること。
