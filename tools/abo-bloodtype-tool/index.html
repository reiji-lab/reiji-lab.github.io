03 / THE RULE

しくみを理解する

01

親から1個ずつ

ABO遺伝子は、両親から1個ずつ受け継ぎます。2個の組み合わせによって血液型が決まります。

02

AとBは両方現れる

AとBが組み合わさるとAB型になります。これは「共優性」と呼ばれます。

03

Oは隠れることがある

AOならA型、BOならB型になります。OOの組み合わせではO型になります。

このシミュレーターについて

一般的なABO式血液型の単純な遺伝モデルを使っています。まれな遺伝子変異や特殊な血液型（cis-AB型、ボンベイ型など）は扱いません。血液型だけで親子関係を判断することはできません。また、A型・B型という血液型だけではAA/AO、BB/BOの区別がつかないため、確率を1つに決めることはできません。
