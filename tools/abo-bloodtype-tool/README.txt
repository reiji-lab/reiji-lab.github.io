reiji-lab | ABO血液型 遺伝シミュレーター

【ファイル】
index.html   画面のHTML
style.css    レイアウトとデザイン
app.js       遺伝計算・選択UI・一覧表

【使い方】
3ファイルを同じフォルダに置き、index.html をブラウザで開きます。
Webサーバー上に配置する場合も、そのまま同じフォルダにアップロードしてください。
外部ライブラリ、外部API、ビルド作業は不要です。

【機能】
- 親の血液型（A/B/AB/O）選択
- A型・B型の遺伝子型（AA/AO、BB/BO）の指定と「不明」状態
- 遺伝子型が不明な場合：生まれる可能性がある型のみを表示
- 両方確定した場合：A/B/AB/O型の正確な理論確率を表示
- 2×2 パネット方眼（組み合わせ表）の自動表示
- 親の血液型による10パターン一覧
- 遺伝子型による21パターン一覧とシミュレーターへの反映
- 表示中の組み合わせによる一覧絞り込み
- スマートフォン・PC対応

【注意】
一般的なABO式血液型の単純な遺伝モデルです。
特殊な遺伝子変異や血液型は対象外です。
血液型だけで親子関係を判断することはできません。
