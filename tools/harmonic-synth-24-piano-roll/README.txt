Harmonic Synth 24 — Ratio Piano Roll | reiji-lab
================================================

構成
----
index.html : 画面
style.css  : デザイン
app.js     : ピアノロール／Web Audio API／倍音合成

起動
----
index.html を Chrome / Edge などで開きます。
公開時はフォルダ一式をそのまま Web サーバーにアップロードしてください。
外部ライブラリは不要です（Web Audio API はブラウザ内蔵）。

使い方
------
1. 基準周波数（デフォルト C4 = 261.625565 Hz）を設定します。
2. 左側の比率（例：3/2、23/16、81/80）を音ごとに設定します。
3. タイムラインの空白をクリックすると音符が置かれます。
4. 音符を横方向にドラッグして位置を移動します。
5. 音符右端の薄い領域をドラッグすると長さが変わります。
6. 音符を選択すると下の編集欄で開始拍・長さ・個別音量を数値で変更できます。
7. 何も置かない区間が休符に相当します。
8. 「＋ 音を追加」で音程行を増やせます（初期10行、最大40行）。
9. テンポ・拍子・小節数・グリッド・横軸拡大率・横スクロールを変更できます。
10. 「▶ 自動演奏」で演奏できます。音色は現在の24倍音設定を使用します。
11. 曲の保存・読込ではJSONを使用しますが、JSONを手書きする必要はありません。

初期サンプル
----------
3/4拍子 × 14小節、72 BPM。
小長谷禮司が打ち込んだ「God Save the King（英国国歌）」の純正比率演奏データを初期表示します。
3/4拍子、14小節、72 BPM、28音程行、163音符。
添付されたJSONを変更せずに初期データとして組み込んでいます。
音高・音価・音量・ミキシング設定を推測や平均律補正によって変更していません。
「禮司の初期データに戻す」で初期曲・音色を復元します。

補足・制限
----------
* 1拍 = 四分音符。空白部分は休符として扱われます。
* 最大40音階行、最大512個の音符イベント、最大64小節。
* 音符イベントの開始時刻は AudioContext の時計で予約して再生しています。
* 曲全体で使う音色は再生開始時点の24倍音設定です（再生中変更は次回反映）。
* 正弦波以外の波形を選ぶと、選んだ倍音の整数倍成分が新たに発生します。
* 実音の音響特性はブラウザ・OS・オーディオ機器に依存します。
* 第24倍音までの加算合成は、素数23を使う23-limitの音律とは別の概念です。

フォルダ名: harmonic-synth-24-piano-roll
配置URL例: https://reiji-lab.org/harmonic-synth-24-piano-roll/

【拍子の切り替え】
2/4・3/4・4/4・6/4を選択できます。変更時は音符の発音位置と長さを保持し、
配置済みの音符がはみ出す場合は小節数を自動で増やします（最大64小節）。
例：初期サンプルの4/4・4小節（16拍）を3/4にすると3/4・6小節になります。
なお既存の音符を新しい拍子に合わせて自動的に移動するものではありません。


【3連符に対応】
----------------
グリッドに「4分3連符（2/3拍）」「8分3連符（1/3拍）」「16分3連符（1/6拍）」を追加しました。
8分3連符ならグリッドを「8分3連符」に切り替えて、同じ音程行の連続3マスをクリックすると、
1拍の中で3音が均等に鳴ります。空白クリックで追加する音符の初期長も1/3拍になります。
各音符はドラッグで移動、右端をドラッグして3連符の単位で伸縮できます。
音符詳細の「開始位置」「長さ」には、1/3、2/3、1/6、5/3 などの分数を直接入力できます。
グリッドは新しい音符の配置・ドラッグ時の刻みにのみ影響し、既存音符を勝手に移動しません。
JSONのstart/durationは従来どおり拍単位の数値で、従来のJSONも読み込み可能です。
現在のグリッド（snap）を新規保存時には記録します（以前の保存データは16分グリッドとして読み込み）。


【音色／ミキシングの書き出し】
---------------------------------
「曲を保存（JSON）」：演奏データ＋24倍音の設定をまとめて保存。
「音色だけをJSON保存」：24倍音の波形／レベル／ミュート（＋基準Hz・マスター）を保存。
「ミキシング情報をダウンロード（JSON）」：マスター音量、24倍音、各音程行の音量、各音符の音量を独立ファイルで保存。
「ミキシング情報を読み込む」：同じ構造の曲に、音量・音色設定のみを再適用。発音位置・音価・音程比は変更しません。
曲の構造が異なる場合は誤適用を防ぐため読み込みを拒否します。

データ同梱
---------
reiji-lab-ratio-roll-song.json: 禮司提供のオリジナル曲データ（変更なし）。
default-data.js: 上記JSONをローカルHTMLでも初期表示できるようにしたスクリプト。

重要：試作品です。周波数／位相／実際のスピーカー出力の精密な実測検証は未実施。

開発クレジット: Developed with ChatGPT by OpenAI


【サンプラー（マイク録音）機能】
---------------------------------
1. HTTPSで公開されたページ、またはlocalhost等で開いてください。
   Chrome / Edge のマイク権限許可が必要です。ローカルfile://での許可はブラウザ環境により異なります。
2. 「● マイク録音」を押し、単音を録音。「■ 録音終了」で取り込み。最大10秒。
   マイク音声はこの端末のブラウザ内で処理し、外部送信しません。
3. 必要に応じて「録音した音の基準周波数」を入力（録音した実音の音高）。
   例：C4（約261.625565Hz）、A4（440Hz）。自動で基音を推定する機能はありません。
4. 音源を「録音した音（サンプラー）」にすると、ピアノロールの周波数比を保って
   自動演奏できます。24倍音ミキサーに戻すと従来の合成音で再生します。
5. 録音した音は「サンプルをWAV保存」で保存し、後から「音声ファイルを読み込む」で復元。
   曲JSONには音声波形は埋め込まれません。音声ファイルもセットで共有してください。

注意：再生速度を変えて音高を変えるシンプルなサンプラーです。
音高とともに再生速度も変わり、長い音ではループを繰り返します。
ループのつなぎ目や元録音の音程精度、サンプル固有の音色変化は未検証です。
モノラル化・無音トリム・音量正規化した音声を使用します。
マイク利用時、ノイズ抑制と自動ゲインを無効にするようブラウザへ要求しますが、
OS・ドライバーによっては適用されない場合があります。


【12平均律ピアノロール（追加）】
---------------------------------
画面上部の「音程比（純正調・任意比率）」と「12平均律（鍵盤）」で切替。
音程比モード：従来どおり任意の周波数比、最大40音程行。禮司の英国国歌が初期データです。
12平均律モード：C2からB6まで60鍵（5オクターブ）の固定鍵盤。初期状態は音符なし。
12平均律の計算は f = A4基準Hz × 2^((MIDI番号-69)/12) です。
A4基準の初期値は440Hz（画面内で400～480Hzに変更可能）。
鍵盤をクリックして音色を試聴できます。グリッド、3連符、移動・長さ変更、音符音量は共通です。
24倍音合成とマイクサンプラーのどちらでも演奏できます。
2つのピアノロールは別の音符データとして保持します。切替では音符を変換・変更しません。
テンポ・拍子・小節数・グリッド・音源・倍音音色は両方で共通です。
「曲を保存（JSON）」は両方の音符、A4基準Hz、現在のモードをまとめて保存します。
旧版（version 1）の比率JSONも読み込み可能です。旧版読み込み時、12平均律は空です。
新ファイルは version 2 で、旧版互換のため root.lanes に比率データを残し、
pianoRolls.ratio と pianoRolls.tet に両方の音符を格納しています。
ミキシング情報は表示中の方式についてのみ保存・適用します（modeタグで誤適用を防止）。
「12平均律の音符をすべて消去」は比率側を変更しません。
比率側の「禮司の初期データに戻す」は比率曲と共通の音色・テンポ等をリセットします。
マイクで録音した音声本体は従来どおり曲JSONに含まれません。WAVを別途保存してください。
