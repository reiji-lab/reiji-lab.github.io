Harmonic Synth 24 — 禮司の英国国歌・両モード初期曲版

使い方
1. index.html をブラウザで開いて動作確認してください。
2. GitHub Pages では既存の harmonic-synth-24/ の index.html と差し替えます。
3. 初期表示は従来どおり比率モードです。上部の「12平均律」に切り替えると禮司の12平均律版が入力済みです。
4. それぞれのモードで「初期データに戻す」を使うと、そのモードの英国国歌が復元されます。
5. 「合成波形」のすぐ下の試聴ボタンは、ページ上部にある試聴ボタンと同じ機能です。

収録データ
純正比率ピアノロール: 163音（14小節、3/4拍子、72 BPM）
12平均律ピアノロール: 163音（A4=440 Hz）
波形・倍音ミキサー: 禮司の修正版JSONの24倍音設定を反映

同梱の reiji-lab-piano-roll-song.json は修正済みの両モード・163音データの控えです。
ユーザー保存のJSONを読み込む機能、モード切替、サンプラー、JSONダウンロード機能は維持しています。
なおWebAudioの音声出力・ブラウザ互換性・端末ごとの最終確認は公開前に実機で行ってください。
