Harmonic Synth 24 — Ratio Piano Roll | reiji-lab
================================================

構成
----
index.html : 画面
style.css  : デザイン
app.js     : ピアノロール／Web Audio API／倍音合成

起動
----
index.html を Chrome / Edge などで開きます。
公開時はフォルダ一式をそのまま Web サーバーにアップロードしてください。
外部ライブラリは不要です（Web Audio API はブラウザ内蔵）。

使い方
------
1. 基準周波数（デフォルト C4 = 261.625565 Hz）を設定します。
2. 左側の比率（例：3/2、23/16、81/80）を音ごとに設定します。
3. タイムラインの空白をクリックすると音符が置かれます。
4. 音符を横方向にドラッグして位置を移動します。
5. 音符右端の薄い領域をドラッグすると長さが変わります。
6. 音符を選択すると下の編集欄で開始拍・長さ・個別音量を数値で変更できます。
7. 何も置かない区間が休符に相当します。
8. 「＋ 音を追加」で音程行を増やせます（初期10行、最大40行）。
9. テンポ・拍子・小節数・グリッド・横軸拡大率・横スクロールを変更できます。
10. 「▶ 自動演奏」で演奏できます。音色は現在の24倍音設定を使用します。
11. 曲の保存・読込ではJSONを使用しますが、JSONを手書きする必要はありません。

初期サンプル
----------
4/4拍子 × 4小節、72 BPM。
C → F → G → C の和音を、平均律へ量子化せず、各行の比率で発音します。
これは操作確認のための例であり、以前のGod Save the King譜面の変換ではありません。

補足・制限
----------
* 1拍 = 四分音符。空白部分は休符として扱われます。
* 最大40音階行、最大512個の音符イベント、最大64小節。
* 音符イベントの開始時刻は AudioContext の時計で予約して再生しています。
* 曲全体で使う音色は再生開始時点の24倍音設定です（再生中変更は次回反映）。
* 正弦波以外の波形を選ぶと、選んだ倍音の整数倍成分が新たに発生します。
* 実音の音響特性はブラウザ・OS・オーディオ機器に依存します。
* 第24倍音までの加算合成は、素数23を使う23-limitの音律とは別の概念です。

フォルダ名: harmonic-synth-24-piano-roll
配置URL例: https://reiji-lab.org/harmonic-synth-24-piano-roll/

【拍子の切り替え】
2/4・3/4・4/4・6/4を選択できます。変更時は音符の発音位置と長さを保持し、
配置済みの音符がはみ出す場合は小節数を自動で増やします（最大64小節）。
例：初期サンプルの4/4・4小節（16拍）を3/4にすると3/4・6小節になります。
なお既存の音符を新しい拍子に合わせて自動的に移動するものではありません。


【3連符に対応】
----------------
グリッドに「4分3連符（2/3拍）」「8分3連符（1/3拍）」「16分3連符（1/6拍）」を追加しました。
8分3連符ならグリッドを「8分3連符」に切り替えて、同じ音程行の連続3マスをクリックすると、
1拍の中で3音が均等に鳴ります。空白クリックで追加する音符の初期長も1/3拍になります。
各音符はドラッグで移動、右端をドラッグして3連符の単位で伸縮できます。
音符詳細の「開始位置」「長さ」には、1/3、2/3、1/6、5/3 などの分数を直接入力できます。
グリッドは新しい音符の配置・ドラッグ時の刻みにのみ影響し、既存音符を勝手に移動しません。
JSONのstart/durationは従来どおり拍単位の数値で、従来のJSONも読み込み可能です。
現在のグリッド（snap）を新規保存時には記録します（以前の保存データは16分グリッドとして読み込み）。
